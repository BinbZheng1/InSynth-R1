4. Each reactant must have at least one element appearing in the product.

10. If the reaction obviously contradicts objective facts, i.e., the reactants clearly cannot produce the stated product, delete that JSON entry.
11. The product, the reactants and their roles must be supported by the source paper, and the paper must clearly report that the reactants are used to synthesize the product; otherwise delete that JSON entry.
12. If the reaction does not meet the requirements, delete that JSON entry.
13. Carefully check whether every reaction complies with the constraints. The dataset requires high-quality reaction equations; reactions must comply with the constraints, and reaction equations that violate the constraints will have adverse effects.
